# 🔬 Pars Azma Equipment Control Center

A professional-grade, full-stack laboratory management portal built to monitor, manage, and analyze industrial laboratory equipment. This platform serves as a centralized IoT/SCADA-style web dashboard for lab directors to track live telemetry, manage maintenance schedules, and resolve critical system alerts across their hardware fleet.

Developed as a 20-day engineering internship sprint prototype for Pars Azma.

## ✨ Key Features

* **Live Overview Dashboard:** High-level fleet KPIs, operational status distributions, and a dynamic real-time system activity feed reflecting the latest hardware events and alerts.
* **Dynamic Device Consoles:** Individualized control pages for each registered instrument (e.g., Incubators, Centrifuges, Vacuum Ovens). Includes hardware specifications, calibration status, and Recharts-powered 24-hour telemetry tracking.
* **URL-Driven Alert Management:** A robust incident tracking system featuring persistent, URL-based state management for filtering alerts by severity (Critical, Warning, Info), timeframe, and text search.
* **Analytics & Telemetry:** Interactive data visualizations tracking system temperature stability, network uptime, and trailing 7-day incident frequencies.
* **Compliance & Reporting:** Interface for generating ISO-compliant audit logs, historical telemetry exports, and maintenance certificates.
* **Server Actions:** Full-stack Next.js Server Actions handling direct PostgreSQL database mutations (e.g., registering new devices) with instantaneous UI cache invalidation.

## 🛠 Tech Stack

* **Framework:** Next.js 16 (App Router)
* **Library:** React 19
* **Language:** TypeScript
* **Database & ORM:** PostgreSQL with Prisma
* **Styling:** Tailwind CSS v4
* **Data Visualization:** Recharts
* **Icons:** Lucide React

## 🗄 Database Architecture

The PostgreSQL database is managed via Prisma ORM and consists of four primary relational models:
* **Organization:** Facilities or laboratories operating the equipment (e.g., "Central Lab").
* **Device:** The laboratory instruments, tracking `serialNumber`, `modelName`, `status`, `targetTemp`, and `calibrationStatus`.
* **Alert:** Incident logs linked to specific devices, categorized by `severity` and `status`.
* **TelemetryLog:** Time-series temperature and environmental data points generated by the equipment.

## 🚀 Getting Started

### Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed and a running instance of [PostgreSQL](https://www.postgresql.org/).

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/yourusername/parsazma-portal.git](https://github.com/yourusername/parsazma-portal.git)
   cd parsazma-portal
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory and add your PostgreSQL connection string:
   ```env
   DATABASE_URL="postgresql://USER:PASSWORD@localhost:5432/parsazma?schema=public"
   ```

4. **Initialize the Database:**
   Run the Prisma migrations to build the schema, generate the TypeScript client, and seed the database with realistic laboratory test data:
   ```bash
   npx prisma migrate dev
   npx prisma generate
   npx prisma db seed
   ```

5. **Start the Development Server:**
   ```bash
   npm run dev
   ```
   Navigate to `http://localhost:3000` in your browser to view the portal.
